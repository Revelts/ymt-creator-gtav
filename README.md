# ymt-creator-gtav

Personal tooling for packing GTA V addon clothing on macOS and Linux.

- **[YMTPack/](YMTPack/README.md)**: `ymtpack`, a cross-platform CLI. It merges
  addon clothing packs, renumbers and renames the stream files, and writes a
  ready FiveM resource with a fresh `.ymt` and optional creature metadata for
  heels and hats.
- **YMTEditor/**: the original Windows (WPF) YMT editor this repo started from.
  YMTPack reuses its bundled `packages/CodeWalker.Core.dll`.
